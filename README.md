
# (ENGLISH)

## Telegram Downloader Bot

### Telegram bot for download video or photo on **youtube**, **pinterest**, **tiktok**.

### 🐍 Project write on Python and have open source.

## ✨Features:
### · 📹 download video with youtube
### · 📌 download video with pinterest
### · 🎵 download video with tiktok
### · 🖼️ download photo with tiktok and pinterest
### · 🛠️ Set Settings download
### · 🤖 Auto send downloaded file in telegram

## 🌐 Supported platform:
### · ▶️ Youtube
### · 🎵 Tiktok
### · 📌 Pinterest

### For downloading video - use yt_dlp, for photo with pinterest - pinterest-downloader, and for photo with tiktok - gallery-dl

## How to install and runnig?

### 1. Clone project
```
git clone
```
### 2. Go to the directory
```
cd bemburmalda
```
### 3. Create file in the project root
### file example_token-bot.env - this is a example for file token-bot.env!!!
```
token-bot.env
```
### 4. add this inside
```
token = your_token_bot
```
### You can get token from @BotFather

### 5. Run the bot
```
python3 main.py
```

## 📖 How to Use?
### 🤖 Start the Telegram bot.
### 🔗 Send it a link to a video or an image.
### ⚙️ Set the required parameters.
### ⬇️ The bot will download the requested file.
### 📤 The bot will send the downloaded file to you.
